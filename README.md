# Portfólio - Douglas Rocha

Portfólio pessoal desenvolvido com Next.js para apresentar a atuação profissional como desenvolvedor front-end. O projeto reúne informações sobre perfil, serviços, cases, habilidades técnicas, currículo e um formulário de contato funcional.

## Link de visualização

[https://douglas-rocha-portfolio.vercel.app/](https://douglas-rocha-portfolio.vercel.app/)

## Sobre o projeto

A aplicação foi criada com foco em performance, responsividade e boa experiência de navegação. A página inicial apresenta seções de destaque, sobre, serviços, cases, skills e contato. Também há uma página dedicada aos cases, com projetos pessoais e profissionais desenvolvidos para e-commerces, sites institucionais e aplicações front-end.

O formulário de contato utiliza uma rota de API do Next.js para envio de e-mails com Nodemailer e proteção com Google reCAPTCHA.

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- React Icons
- React IMask
- React Google reCAPTCHA
- Nodemailer
- Next Sitemap
